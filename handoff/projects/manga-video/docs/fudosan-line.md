# 不动产讲解线

2026-11-05 用户定：另开一条线，和税务图解共用引擎、流程和配音，形象单独一套。

## 怎么开工

只有开在「视频·不动产讲解」分组的对话才走这条线；税务图解组的期讲房子也用税务背景（用户 2026-11-05 定）。

用户写好稿子存进云盘 `视频制作/不动产讲解/01-文稿/<题目>.md`（也可能直接贴在对话里），再在侧边栏「视频·不动产讲解」组开新对话，说「不动产讲解：<文件名>」。成片放云盘 `写作/不动产讲解/<题目>/成片/`。一期一个对话，这个组里的「不动产讲解视频项目」对话负责维护这条线的模板和规矩。

## 形象

- 老师、芝士的脸和声音不变，还是两人对话（老师 gou，芝士「芝士机器人」）。
- 背景：住宅街（浅蓝天 + 底部两层淡青色房屋剪影），不用放射线、格子或线条。
- 老师：素色藏青西装、素色深绿领带，不戴胸牌、徽章。芝士：绿色卫衣、挂绳和钥匙，是想买房的人。
- 代码在 `src/episode/looks.tsx`，`visuals.json` 顶层写 `"look": "fudosan"` 就生效；不写就是税务线原样。

- 面向中国观众：白底上放红色、橙色的圆形或单个图形，容易看成日本国旗，人物、封面、物件都别这么画（2026-11-05 用户指出，胸牌因此去掉）。

## 新建一期

```
node pipeline/new-episode.mjs <期名> --line fudosan
```

之后的步骤和税务图解一样（技能 `tax-explainer-video`）：facts.md → 官方截图 → states.md → scenes.mjs → 审片 → 配音 → 出片。

## 这条线自己的规矩

- 章节卡 `chapterTitle` 写 `"no": "房"`、`"kicker": "牛丼老师的不动产课"`，不要从税务期抄「税」和「税务课」。章节卡和片头卡都写 `"color": "#3A4A6B", "soft": "#E6E9F0"`：默认的橙色圆号放在白卡上像日本国旗。
- 不推荐具体楼盘，不判断某处房子该不该买。简介写明「不是中介、不介绍物件」。
- 出处优先法务省、国土交通省、国税厅、总务省、自治体官网。
- 颜色含义沿用税务线：橙是付出去的钱，绿是省回来的钱，黄是自己负担，总额用中性蓝。

## 一、配乐（🆕 全部是今天改的）

| 项 | 以前（10-06） | 现在（10-07） |
|---|---|---|
| 音乐表怎么写 | 一章一行 | **按结构段写**（开头悬念段 / 主体 / 收尾），不按章 |
| 什么时候换曲 | 每章轮换 B、C 两首 | 按结构段换；**章与章交界不换曲** |
| 有音乐的时间 | 85–95% | **95% 以上**（只有原声、小剧场、计划好的全静不算） |
| 曲子数 | 没规定 | 12 分钟以内 2–4 首，30 分钟左右 3–6 首 |
| 曲子厚度 | 「极简、几乎没鼓的长音垫」 | **不能单薄**：至少两层（如钢琴 + 弦乐），主曲约 80 拍/分钟，收尾曲快约 10% |
| 音乐多响 | 比人声低约 20 dB | 从低约 20 dB 起试（参考片 16–26 dB） |
| 人一说话音乐压多少 | 固定压 7 dB | **先出 60 秒对比样**（压 7 / 压 3 / 不压）给你听，你定；定之前默认 3–4 dB |
| 刻意抽掉音乐 | 关键结论前抽 2–5 秒 | 12 分钟以内全片只 2–3 次，只放在结构转折处（开头结束、全片约 60% 处、进收尾） |
| 句子之间没空隙时 | 没规定 | 关键句开口前 0.3 秒把音乐退掉，这句只留人声 |
| 结尾 | 没规定 | 最后约 60 秒只留低音，最后一句和音乐一起断，再留 2.5 秒全静 |
| 旧曲库 B、C | 首选 | B、C 偏薄（B 几乎没低音），只当轻快段备用 |
| 新闻原声那几秒 | 音乐 ≤ −35 LUFS 或没有 | **是没有，不是压低**；USJ 那份总装脚本已经能整段去掉（⭐ 刚核实） |

不变的：有歌词、哼唱、合唱的曲子一律不用；生成的曲子先机器筛人声，再人耳听；整片响度 −14 LUFS。

## 二、音效

### 🆕 今天凌晨加的

- 一张「音效清单」：盖章「咔、嗒」两下（比人声峰值高约 5 dB）、快门（和人声一样响）、胶片噪声（低约 2 dB）、低频「咚」（全片 1–2 次）。
- 当时的密度规定：平均约 1 分钟 1 个；不加打字声；要更丰富得你另外拍板。**→ 这一条已被下面 ⭐ 取代。**

### ⭐ 刚才改的：每个动作配一个音效

| 画面动作 | 配什么声 |
|---|---|
| 原件纸页、照片卡、便签落下 | 纸张翻动 / 纸张滑入 |
| 新闻画面定格、切到满屏照片 | 快门 |
| 荧光笔划线、红笔圈、箭头 | 马克笔（**待做**） |
| 放大镜到位 | 很轻的「嗒」（**待做**） |
| 数字滚动、横条长出 | 嘀嗒一串，最后「叮」对准数字停下那一下 |
| 印章 | 盖章「咔、嗒」两下 |
| 弹字、时间线节点 | 「啵」的弹出声（三个版本轮流） |
| 拟声大字、集中线 | 低沉的冲击声（最重的那种全片 ≤ 6 次） |
| 速度线、视差照片 | 「嗖」 |
| 打字机金句卡 | 卡片落下 + 逐字打字声（**待做**） |
| 换章 | 上扬铺垫声 + 冲击声 |

- 标题、出处、字幕这类普通文字出现**不算动作**，不配声；被挡住看不见的也不配。
- 两个动作挨得太近（不到 0.3 秒）只响较重的那一个；响的那几种（快门、冲击、盖章）之间至少隔 2.5 秒。
- 轻的声音（纸、嘀嗒、弹出）都比说话声小 20–30 dB，听得到但不抢话。你听了嫌吵，先整体再压低，不删声。
- 音效全部是程序算出来的，**不花钱、没有版权问题**；音效库直接用 USJ v6 那套。
- 还缺「嗒」「马克笔」「打字」三种，做好之前临时用嘀嗒和纸张声顶上。

## 三、总装（把画面、配音、音乐、音效拼成成片）

### 🆕 今天凌晨改的

- **三步防呆**（起因：USJ v5 的总装脚本把配乐路径算错了，脚本找不到文件也不报错，整片一秒音乐、一个音效都没有，还交付了）：
  1. 总装前检查配置里每个声音文件都在；
  2. 自己写的脚本，路径一律先展开再拼；
  3. 跑完立刻看拼接记录：配乐不是空的、音效数大于 0，不对就停。
- 配乐先按音乐表拼成**一整条**，再交给总装脚本（脚本还不会「按段指定曲子」）。
- 章节卡改成**可选**：10 分钟上下的片子默认不做章节卡，靠右上角章名换章。
- 新闻原声每段 ≤ 10 秒，硬切进出；纸面切进满屏实拍可以用「老电视 + 故障帧」转场，快门声落在切的那一刀上。
- 画面节拍：约 3 秒一个新动作，一屏一个主效果，慢推只给停留超过 15 秒的屏。

### ⭐ 刚才改的：画面改成 v6 镜头脚本

- 以后每期都照 USJ v6 做：稿子和配音不变；配音定稿后，**每个镜头写一份画面脚本**，用组件库摆放大镜、荧光笔、数字滚动、印章、拟声字、视差照片、打字卡，出现时刻对准旁白念到的词。
- 每写完一章先出静帧拼图给你看，你点头再往下写。
- **改画面更快了**：改哪个镜头只重渲那一个，其余几秒钟复用，不用再算接缝。
- 总装脚本改用 USJ 那份（比日本企业那份新：原声段音乐整段去掉、能按旁白锚点抽掉音乐）。

## 四、质检

### 🆕 今天凌晨加的

- **配乐和音效不能为 0**：一行检查，不过就停。
- **句子之间有没有音乐**：检测成片里有没有掉到很静的空隙；几十个空隙落在句子之间 = 配乐没进去（USJ v5 有 47 处）。
- **画面静止太久**：静止 ≥ 9 秒的地方逐条列出，不是金句卡、揭晓、读原件的都要改（检测参数要先拿 USJ v5 校准一次）。
- 独立复查清单从 8 项扩到 14 项，新增：⑨ 档案纸样式、⑩ 残留（TODO、占位、空框、黑边）、⑪ 节奏、⑫ 声音补充（配乐不为空、原声 ≤ 10 秒、音乐里没人声）、⑬ 隐私打码、⑭ 一期只用一套模板。
- 顺带改的交付规矩：封面你说不标 AI 时，封面上任何 AI 标识都不放；YouTube 简介导语改成四小段（钩子 → 定位 → 路线图 → 一句结论），章节名用问句或判断句。

### ⭐ 刚才加的

- 每个动作都登记了音效：一段检查脚本，退出码 1 就列出哪个镜头的哪个动作没配声。我拿 USJ 的 3 个示范镜头试了：**16 个动作只有 4 个有声**（照旧规矩写的），按新规矩要补。
- 成片里的音效数要和登记数对得上（差不超过 5%）。
- 复查清单第 ⑮ 项：音效对准落点、轻声不盖旁白、放大镜译文和原件一致、拟声字不拿来说数字或事实、视差照片不晃得人头晕。

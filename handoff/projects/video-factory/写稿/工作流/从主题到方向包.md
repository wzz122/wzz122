# 从一个主题到可拍板的方向

2026-10-06 用户确定：资料工作由助手主动完成，方向由用户拍板。日语长视频、字幕、相关新闻和评论由助手寻找；用户额外提供的材料随时并入。

## 你给什么

一句主题、一个新闻链接、一份字幕，任选一种即可。有明确想表达的立场、受众或时长时一起说；没有就先做研究，不要求你先下结论或找齐资料。

## 我交什么

1. 找到的日语长视频、相关新闻与原件索引，标出哪些读到了全文/字幕、哪些看过画面。
2. 关键事实核查、来源之间的转引关系和待核实项。
3. 可访问的YouTube/Yahoo评论样本：观众关心什么、误解什么；写清采样方法与缺口。
4. 3–5个不同方向，每个包含题眼、标题、核心论点、开头、简短章节骨架、证据与可用画面、预计时长、最关键缺口；给一个推荐理由。

你选一个或组合几个，我记录决定并继续写。方向包里已确认的骨架不重复审批；稿件通过现有校对页审阅，后面试听、审片和发布决定继续保留。

## 哪些能自动做，哪些不能保证

| 环节 | 能力与实际边界 |
|---|---|
| 搜日语长视频 | 能按主题、日期、来源类型和可见观看量筛选；不能保证搜索结果覆盖全网或绝对最高播放量 |
| 取字幕 | 能取可访问的人工字幕/自动字幕，保存原语种和时间码；本次已实取一支10分33秒日语视频，共161段ASR字幕 |
| 无字幕视频 | 音频能正常取得时可用本地ASR，16GB机器串行运行；专名和数字需要复听 |
| 新闻全文 | 能取公开网页并追原件；付费墙、登录/验证码、地域或平台限制可能导致缺口 |
| 评论 | 能采集正常可见样本并整理；关闭/删除/限制评论无法保证取到，热门排序也不能代表整体民意 |
| 事实与画面 | 字幕是线索；重要说法另核原件。读文字、看帧、听原声分别记录，不互相冒充 |
| 方向和立场 | 我提出，你决定。不能把助手的建议或嘉宾/网友观点记作你已经选定的立场 |

## 制作质量的固定方向

每期说明我们新增了哪份证据、纠正哪个口径、画清什么关系。用证据推动叙事，人物/物件贯穿，照片原声保留现场感；复杂数字用图解，长片加章节导航。参考节目的名字与辨识性元素不进入成片。先检查代表画面，再扩展全片；原件、分镜、音轨、字幕和版本持续保留。

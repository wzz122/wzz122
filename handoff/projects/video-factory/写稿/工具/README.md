# 工具（每期通用）

| 文件 | 用途 | 用法 |
|---|---|---|
| `pdfshot` | 把官方 PDF 某一页渲染成 1920 宽截图，自动给关键句加黄底红框（2026-10-05 起按行取框并校正偏高，可用环境变量 PDFSHOT_DY 微调；关键句要按 PDF 里的换行拆成几段传） | `./pdfshot 文件.pdf 页码 输出.png 上边比例 下边比例 "关键句1" "关键句2"`（比例 0–1，用来裁上下） |
| `pdfbox` | v6 用：官方 PDF 某页 → **干净**整页截图（不画任何标记）+ 关键句像素框 `<名>.框.json`，给 docpage / highlighter / lens 定位（2026-10-10 T019 新增；横版旋转页已修） | `./pdfbox 文件.pdf 页码(0=自动找第一句所在页) 输出.png 1800 "关键句" "前半||后半" "~2:27"`（跨行用 `||` 连，`~N:` 取本页第 N 次出现） |
| `imgtool` | 裁掉截图无关部分，并在底部加「【译】中文翻译＋来源」说明条 | `./imgtool 输入.png 输出.png x y 宽 高 "【译】……" "来源：……"`（宽高填 0 表示到边） |
| `vcard.py` | 竖屏截图卡：从原始截图重新取景（可多段拼接、右边渐隐、表格分两列），配 34px 大字【译】条和来源，输出 1840 宽 PNG（竖屏显示 920 宽）；译文只写画面里看得见的内容，`{…}` 里的词不拆行 | `python3 vcard.py 配置.json [键…]`（配置见文件开头；东大那期：`资料/2026-09-东大新总长/截图/竖屏卡片.json`） |
| `mshot.mjs` | 手机宽度网页截图：430px 宽、3 倍像素打开网页，正文自动重排成短行大字；关键句加黄底红框；只截指定段落 | `node mshot.mjs 配置.json [键…]`（例：`截图/手机截图.json`）；竖屏版里网页截图都用它，比桌面截图放大两倍 |
| `wshot.mjs` | 桌面宽度网页截图（横屏用，mshot 的桌面版）：1280 宽、2 倍像素，关键句黄底红框，可裁左右、隐藏元素 | `node wshot.mjs 配置.json [键…]` |
| `录屏.mjs` | **（2026-10-23，AI 片）** 照脚本操作网页并逐帧录成 1920×1080 / 30 帧 mp4：动画光标、点击涟漪、逐字输入（中文可）、按键、平滑滚动、关键句黄底红框划出、执行 JS；`{"wait":3,"live":true}` 按真实速度录网页自己的动画（流式回答）。另出 `.时间点.json`（每一步在视频里的秒数）。不用装 Playwright，复用视频工厂的 cdp.mjs | `node 工具/录屏.mjs 配置.json [--keep]`（配置格式见脚本开头；例子 `工具/_自测/录屏/录屏-本地.json`）。字小就在脚本里 `{"js":"document.body.style.zoom=1.6"}` 或 `"dpr":2` |
| `抽帧质检.py` | 成片质检用：每屏结束前一帧（带字幕）+ 每句字幕中间一帧（只截字幕区），并拼成拼图、导出 subs.json（每句原文与计划断行） | `python3 抽帧质检.py 成片.mp4 timeline.js 输出目录 v`（竖屏）或 `h`（横屏）；只用 ffmpeg，不跑模型 |
| `改稿.py` | **交稿给用户审用这个（2026-10-12 起）**：把稿件旁白摆成一页纯文字，用户直接在网页里改，停一秒自动存回稿件 .md（版式行、大标题、注释原样保留；同步更新视频工厂 1-我的文案/ 里的同名稿；第一次保存前备份成 `xxx.改稿前备份.md`）。只在本机 127.0.0.1 开服务 | `python3 工具/改稿.py 成稿/xxx.md`；不给文件就打开最近改过的稿；用户可以双击 `写稿/改稿.command` |
| `稿件网页.py` | 把视频工厂格式的稿件转成好读的网页并打开（章节导航、每屏一张卡） | `python3 工具/稿件网页.py 成稿/xxx.md` |
| `新闻片段.py` | 按「新闻大写」做法把新闻原片剪成成品：纸纹底、视频不遮台标、左对齐中文字幕与来源条、原声线性响度 | `python3 工具/新闻片段.py 规格.json`（规格格式见脚本开头） |
| `老影像.py` | 把资料影像处理成「老片子」的样子，四个预设：`原样黑边`（保留台标，不调色）、`褐色满屏`（去色染褐 + 颗粒 + 闪烁 + 暗角）、`电视框`（缩到中间、圆角虚边、黑底，可加 `--色调 蓝黄/暖`）、`羽化黑边`（四边渐隐）；按原片比例开窗不裁台标；`--来源` 在左下角加来源小字；只用 ffmpeg | `python3 工具/老影像.py 输入.mp4 输出.mp4 电视框 --in 12 --out 20 --来源 "AP｜1978年"`（`--无声` 去掉原声；对照见 `资料/参考-新闻大写-仪式感期/00-拆解.md` 第四节） |

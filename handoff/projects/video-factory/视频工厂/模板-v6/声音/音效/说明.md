## 用量建议（每 10 分钟换算）

- 过门：riser + hit/嗖，对应底部导航的 7 个章节切换点，约 7–9 组。
- 大冲击 hit-重：≤ 6 次；hit-轻：约 10–15 次（集中线、拟声字）。
- pop、tick、纸张、快门：跟画面元素走，相邻两个至少隔 2.5–3 秒；同一时刻已有过门或冲击就不再叠。
- 被 AI 面板挡住、或画面上看不见的元素不配音效。

## 合成要点

- pop：正弦 1500→700 Hz（35 ms 内指数滑落）+ 1 ms 高通咔嗒 + 一点 220 Hz 垫底，外放不刺耳。
- tick：3.0/3.2/3.5 kHz 正弦 × 2 ms 衰减 + 高通噪声；叮 = 1760/2640/3520 Hz 三分音。
- 快门：两下机械咔嚓（2.2 kHz、1.7 kHz 窄带谐振，间隔 45 ms）+ 120 Hz 短咚。
- 纸张翻动：4–5 个 1.5–7 kHz 随机带通噪声颗粒、间隔逐渐变密，最后 200–600 Hz 纸面拍击；滑入 = 1–6 kHz 摩擦噪声（35–60 Hz 幅度调制当纹理）+ 落定轻拍。
- hit：60→32 Hz 下滑低频 + 140–150 Hz 冲击层（手机外放也能感到）+ 1.2 kHz 低通噪声爆破 + 2 ms 3–6 kHz 咔嗒 + 卷积混响尾（轻 0.7 s、重 1.2 s）。
- riser：时变带通噪声中心 400→7000 Hz（带宽逐渐收窄）+ 三根略失谐的锯齿 110→440 Hz，颤音 4→16 Hz 加速，包络 t^2.5。

# 视频工厂 · 说明书

**一句话**：你往 `1-我的文案/` 里丢一个 `.md` 文本文件，双击 `开始做视频.command`，
几分钟后 `2-成片/` 里就出现一个带画面、带动画、带配音、带字幕的 1080P 视频。

全程不联网、不花钱、不用剪辑软件。

---

## 一、怎么用（推荐：先看版面，再出片）

> **两步走，别一上来就渲染视频。**
> 看版面 15 秒就出结果，出视频要几分钟。先把版面改顺了，再出片。

### 第 1 步：先看版面

双击 **`看版面.command`**（或把文案拖到它图标上）。

十几秒后浏览器会自动打开一个**校对页**：每一屏一张图，旁边写着

- 这屏用了什么版式
- **对应文案的第几行**、原文是什么
- 这屏会念哪几句旁白
- 一个写意见的框

在框里写下要改什么，点右上角 **「复制全部意见」**，直接粘给我。
我会知道该改哪一屏、哪一行。

也可以自己改：校对页已经告诉你是第几行了，打开文案改那几行，再双击一次 `看版面.command`。

### 第 2 步：版面满意了，再出片

双击 **`开始做视频.command`**。

---

## 出片的详细说明

**第 1 步**：在 `1-我的文案/` 文件夹里新建一个 `.md` 文件，按下面第二节的格式写你的稿子。

**第 2 步**：双击 `开始做视频.command`。

> 第一次双击时 macOS 可能弹「无法打开，因为来自身份不明的开发者」。
> 解决：在这个文件上 **右键 → 打开 → 再点「打开」**，以后就不会再问了。

**第 3 步**：等进度条走完。成片会自动在访达里弹出来。
（1 分钟的视频大约渲染 3 分钟；10 分钟的视频大约 25 分钟。）

---

## 二、文案怎么写

先看最简单的样子——**只写这些就能出片**：

```markdown
# 视频标题
> 频道名 | 系列名

## 第一章的名字
这是第一句旁白。
这是第二句旁白。
这是第三句旁白。

## 第二章的名字
继续往下写就行。
```

规则只有 4 条：

| 你写的 | 变成什么 |
|---|---|
| `# 标题` （在最开头） | 视频的片头大标题 |
| `> 频道名 \| 系列名` | 每一屏左上角的小字（频道名可以留空：`> \| 系列名`，这时片头不画短横线和频道名；**不要写「新闻大写」**，那是参考博主的频道名） |
| `## 章节名` | 换一个新章节，右上角会显示 `#1 章节名` |
| 普通一行字 | 一句旁白 + 一条字幕（**一行 = 一句**，建议 10~18 字） |

## 三、让画面更好看（可选，但建议加）

在每个章节里，你可以多写三种东西：

### ① 大标题 —— `#`

```markdown
## 答案和草稿纸
# 两个月前的答案：==有==
两个月前我的答案是，有。
```

- `==文字==` → **黄色荧光笔高亮**
- `**文字**` → **红色强调**
- 连写两行 `#` → 标题分两行

### ② 换一屏 —— `---`

一个章节里画面不想一直不动，用 `---` 隔开，镜头就会移动到新的一屏：

```markdown
## 蒸馏这件事
# 这不是普通蒸馏
过去它是零敲碎打的。

---
# 一个信号
最强的老师，不再公开教课了。
```

### ③ 版式 —— `[版式名] 内容1 | 内容2 | 内容3`

这是最出效果的一条。可用的版式：

| 写法 | 效果 |
|---|---|
| `[卡片] 卷子:抄 ✓ \| 答案:抄 ✓ \| 解题步骤:抄 ✓` | 一排纸卡，冒号后面是印章 |
| `[便利贴] 答案值钱 \| 草稿纸更值钱 \| 推理才是核心` | 散落的彩色便利贴 |
| `[对比] 外界能用的模型:公开发布 \| 内部研究模型:锁在实验室` | 左浅右深两块对比板 |
| `[列表] 第一点 \| 第二点 \| 第三点` | 竖排要点，逐条出现 |
| `[数字] 3 \| 三种结局 \| 取决于两个变量` | 巨大数字 + 说明 |
| `[引用] 人类必须同时证明两件事 \| 竞争力，和控制力` | 红竖线引用块 |
| `[地图] 环球影城 \| 大阪城 \| 关西机场` | 三个红色定位点 |
| `[条形] 中国:38%:38 \| 美国:62%:62` | 横向条形图 |
| `[图] 我的插图.png` | 放你自己的图（图片放进 `1-我的文案/图/`） |

### ⑤ 第二代版式：数据图 / 概念图 / 界面复刻

这批版式会**自己动**——不是整块淡入，而是按旁白进度一点点画出来。

| 写法 | 效果 | 动画 |
|---|---|---|
| `[折线图] 1999:281 \| 2000:403 \| 2001:1171 \| 2002:2064` | 折线图 | **一段段画出来**，讲到最后一个数时**镜头自动推近** |
| `[柱状图] 中国:38 \| 美国:62` | 柱状图 | 逐条从底部长起来，镜头推近最后一条 |
| `[方块图] 23 \| 国企下岗职工` | 100 格填 23 格 | **一格格填色** |
| `[流程] 国企改革 \| 工人下岗 \| 社会风险 \| 最低生活保障` | 带 STEP 01-04 的流程图 | 箭头顺着方向生长 |
| `[靶心] 最该保的人` | 同心圆靶心 | **一圈圈由内往外扩散** |
| `[汇聚] 日本、韩国、中国 \| 一种顽固的直觉 \| 家庭` | 多路汇聚图 | 线条画出来 → 汇聚 → 往下 |
| `[下坠] 5 \| 第1年 \| 第2年 \| 第3年` | 小人下坠 + 刻度 | **加速下落**，刻度一格格掠过 |
| `[热搜] 标题1 \| 标题2 \| 标题3` | 复刻的热搜榜 | 逐条滑入（`==词==` 会标红） |
| `[公文] 标题 \| 正文1//正文2 \| 落款 \| 日期` | 复刻的官方通告 | 整页浮起 + 逐段显现 |

**这批版式的标题会自动挪到左边**，图在右边，不用你操心排版。

### ⑥ 放你自己的图和视频

**第 1 步**：把图片/视频拖进 `1-我的文案/素材/`

**第 2 步**：双击 `看版面.command`。系统会自动：
- 给每个素材做旧（去饱和 + 米黄调 + 提对比），让它跟纸面是一个世界的
- 生成缩略图，放进校对页的素材挑选器

**第 3 步**：在校对页里，每一屏下面有个 **「＋ 加图/视频」**，点开挑一个，再选放在哪：
「整张图」「满屏背景」「画中画」。点「复制全部意见」粘给我，我就写进文案。

也可以自己在文案里写：

| 写法 | 效果 |
|---|---|
| `[画中画] 街景.mp4 \| 说明1 \| 说明2` | 素材嵌在右边（带纸质边框+微倾），说明文字压在上面逐个出现 |
| `[满屏] 机房.jpg` | 素材铺满整屏，左边自动加柔化层保证标题读得清 |
| `[图] 机房.jpg` | 就放一张，带纸质边框 |

**关于视频**：支持 mp4 / mov / webm（H.264 / VP9 / AV1 都行，HEVC 不行）。
视频会跟旁白的时间轴**逐帧同步**，不是让它自己播——所以永远不会错位。
代价是渲染变慢约 60%，只有含视频的镜头慢，纸面镜头照旧。

**做旧强度**在 `engine/config.json` 里调 `mediaGrade`：`0` = 不处理，`1` = 最狠，默认 `0.75`。

**这些内容不会被念出来**，只出现在画面上——旁白永远只念普通行。

### ⑦ 让 AI 生成一段视频（Seedance，**会花钱**）

手绘画不出来的画面（情景再现、空镜、小动画），在文案里写一行：

```markdown
[生成] 清晨的主题乐园入口，游客排长队，镜头缓慢推近
[生成] 夜晚的烟花表演，人群仰望天空 | 8秒 | 720p
[生成] 需要很精细的镜头 | 2.0
[生成画中画] 同样写描述 | 图下面的说明条
```

- 默认：**2.0 迷你版、480p、5 秒**，每段约 **0.17 美元**
- 可以在后面加：`| 4~15秒`、`| 720p`（迷你版 5 秒约 0.38 美元）、`| 2.0`（画质最好的 2.0，480p 约 0.34、720p 约 0.76 美元），写 `| 1080p` 会自动改用 2.0（约 1.7 美元）
- `[生成]` = 满屏视频；`[生成画中画]` = 放成画中画
- **看版面**：只显示「待生成视频」占位，**不花钱**
- **开始做视频**：先列出要生成几段、大约多少钱，**你输入 y 回车才生成**；直接回车 = 不生成、用占位继续出片
- 最多 3 段同时生成；同一句描述只生成一次，存在 `1-我的文案/素材/生成-xxxx.mp4`，以后重渲不再扣费；生成的视频会自动做旧
- 每次实际用量记在 `1-我的文案/素材/生成记录.csv`
- 钱从 BytePlus「按额度付费」余额里扣，花完就停，不扣信用卡；迷你版和 2.0 各设了 500 万 token 用量上限
- 单独试一段：`node engine/seedance.mjs "描述" 8秒`

### ⑧ 笔墨版式：人群 / 印章 / 墨圈 / 声波 / 线描（2026-10-05）

这批画面全是代码画的矢量图，不调用任何生成模型，不花钱；横屏、竖屏都能用。完整示例见 `1-我的文案/示例-笔墨版式.md`（成片在 `2-成片/示例-笔墨版式.mp4`）。

| 写法 | 效果 | 动画 |
|---|---|---|
| `[人群] 远处标签 \| 左侧标签 \| 右侧标签` | 一条路伸向远处，两旁站满人（黑点为主，约两成红点，外沿有人举小红旗）；三个标签都可省 | 路先出来，人**从远到近一排排站出来**，最后出标签和引线 |
| `[印章] 劳民伤财 \| 面子工程 \| 形式主义` | 红底白字做旧印章，四个字排 2×2，最多 4 枚 | **一句旁白盖一枚** |
| `[印章] … \| 注：都能解释一部分 \| 圈：反复/出现` | 印章下面加一行小字；右边加一个墨圈圈住结论（`/` 前是红色大字，后是小字） | 印章盖完出小字，最后一笔画出墨圈 |
| `[墨圈] 排场 \| 年年如此` | 右边一个大墨圈，标题在左 | 一笔画完（约 1.2 秒），圈里的字再出来 |
| `[声波] 热烈 \| **欢迎**` | 老式话筒 + 声波；项目是喊出来的词（最多 3 个），越往后越大，`**词**` 是红字 | 声波一圈圈往外走；**一句旁白出一个词** |
| `[线描] 礼堂.svg \| 台上的人 \| **台下的人**` | 一张 SVG 线稿居中；后两项是左右竖排的毛笔题字（可省） | 线稿**一笔一笔描出来，再上色** |

- `#` 标题在这几种版式里照常可用：人群、声波、线描的标题在左上角；印章不写标题时整体上移。
- 人群、话筒、线稿和标题一起在本屏第一句出现；印章、词、竖排题字跟着后面的旁白一句一个。
- 人群版式的人数是装饰，不代表任何统计数字；要表达具体人数，用 `[方块图]` 或 `[数字]`。

**线稿怎么来**：`[线描]` 用的 SVG 放在 `1-我的文案/素材/`，由 Claude 按当期内容手写（示例：`素材/示例-线描-礼堂.svg`）。写法约定：

- `viewBox` 用 1040×650 左右的横幅；根节点写 `fill="none" stroke="#1c1a17" stroke-width="5" stroke-linecap="round" stroke-linejoin="round"`。
- **一个图形一笔**，先写的先描；有 `fill` 的图形描完轮廓后颜色淡入。20–40 笔合适，太碎会描不完。
- 颜色只用纸面这一套：墨黑 `#1c1a17`、砖红 `#c9412b`、浅粉 `#f3c9bb`、米白 `#f6f1e6`、淡绿 `#cdddb4`。
- 画风按[图像风格与复查规范](视觉规范/图像风格与复查规范.md)：圆角、圆头线、形状简单亲切；不画真实人物的脸，不在 SVG 里写字（字用标题、竖排题字或 `[弹字]`）。
- 画完照规范查两遍：先单看 SVG，再看版面预览和导出帧。

**折线图批注**：`[折线图]` 的数据项后面可以加这几种批注项（都可省）：

```markdown
[折线图] 1995:60 | 1999:110 | 2003:200 | 2005:260 | 图题：某市机动车保有量 · 示意 | 横线：200=200万 | 竖线：2003=转折之后 | 箭头：2003=私家车井喷 | 大字：260万
```

| 批注 | 写法 | 效果 |
|---|---|---|
| 图题 | `图题：文字` | 图左上角的小字图题；**数字是示意时在这里写「示意」** |
| 横线 | `横线：数值=标签` | 一条水平虚线 + 标签 |
| 竖线 | `竖线：数据键=标签` | 在那个数据点画竖虚线，折线画到那里才出现 |
| 箭头 | `箭头：数据键=标签` | 从那个点甩出一支红色弯箭头，下面是红字标签 |
| 大字 | `大字：文字` | 图内左上的红色大数字，折线快画完时出现 |

「数据键」必须和前面某个数据项冒号前的写法一模一样（如 `2003`）。

**用到的字体**（都是 macOS 自带）：行楷 Xingkai SC（毛笔大字、竖排题字）、魏碑 Weibei SC（印章）、Bodoni 72 Oldstyle（大数字）。换一台没有这些字体的电脑渲染，会退回楷体和宋体。

## 四、想调参数

打开 `engine/config.json`：

```json
{
  "fps": 30,            // 帧率，想更省时间可以改 24
  "voice": "Tingting",  // 配音：Tingting(普通话) / Meijia(台湾) / Sinji(粤语)
  "rate": 168,          // 语速，越大越快。170~185 比较像 up 主
  "gap": 0.30,          // 句与句之间停多久（秒）
  "coverHold": 3.2,     // 片头停留几秒
  "tail": 1.2,          // 片尾留白
  "mediaGrade": 0.75,   // 素材做旧强度，0=不处理 1=最狠
  "bgmLoudness": -33,   // 背景音乐响度（详见上面「加背景音乐」）
  "loudness": -14       // 成片目标响度
}
```

### 加背景音乐

把一个 mp3 命名为 **`bgm.mp3`**，放进 `1-我的文案/`，就会自动混进去。系统会自动做三件事：

| 处理 | 说明 |
|---|---|
| **响度对齐** | 先量这首歌本身多响，自动推到 `bgmLoudness`（默认 −33 LUFS）。**换任何一首歌都不用重调音量** |
| **闪避 ducking** | 你一开口，音乐自动压下去 16~22 dB；你一停，音乐浮回来。这是"听得见但从不抢话"的关键 |
| **响度标准化** | 整片拉到 `loudness`（默认 −14 LUFS），正好是 YouTube / B站 的标准 |

音频参数在 `engine/config.json`：

```json
{
  "bgmLoudness": -33,   // 音乐在没人说话时多响。想更轻就改 -36，更明显就 -30
  "duck": true,         // 闪避开关
  "duckRatio": 8,       // 压得多狠，越大压得越死
  "duckRelease": 500,   // 说完多久音乐浮回来（毫秒）
  "loudness": -14,      // 成片目标响度，YouTube/B站 标准
  "bgmFade": 2.5        // 音乐开头淡入几秒
}
```

**选曲建议**（这类解说视频）：要**极简、没有旋律钩子、几乎没有鼓点**的长音垫（ambient / drone / 简单钢琴）。
有鼓点 = 有节奏 = 跟说话的节奏打架。音乐的作用是"填掉沉默"，不是"好听"。

**免费可商用的来源**：
- **YouTube Audio Library**（最安全，可商用、多数免署名）
- **Pixabay Music**、**Free Music Archive**
- **Uppbeat**（免费档要署名）、**Kevin MacLeod / incompetech**（要署名）

> ⚠️ 「无版权音乐」不等于「免费随便用」。很多标着"无版权"的实际要求署名或禁止商用，下载前看清许可。

**只给某一期配乐**：命名为 `文案名.bgm.mp3`（和 `.md` 同名），它优先于通用的 `bgm.mp3`。

## 五、想用自己的声音 / 外部配音（MiniMax 等）

把整条配音命名为 **`文案名.旁白.wav`**（也可以是 `.mp3` / `.m4a`），和 `.md` 放在一起，
双击「开始做视频」就会：跳过 Mac 自带语音 → 用 whisper 把每句字幕对到这条录音上 → 画面跟着真实语音走。

- 录音要**逐字照稿念**（标点、拆行不影响；多念、漏念会让附近几句字幕对不准）。
- 片头停留 `coverHold` 秒后旁白才开始，片尾留 `tail` 秒。
- 字幕按稿子自动拆句：一条最多约 18 字；句末标点后的引号跟着本句；少于 4 字的碎片并进相邻行。
- 第一次用：2026-10-01「东大黑箱」那期（MiniMax 网页版 gou 音色，1.1 倍速，音高 1）。
- 2026-10-06 起默认语速改为 **1.15 倍**（用户定）；给旧期补配音时沿用那期原来的语速。
- **换屏停顿**：整条配音是一口气念下来的，换屏时容易「不喘气」。引擎会在每屏第一句前把停顿补足到 `sceneGap` 秒（`engine/config.json`，默认 0.8；原本已经停够的不动），字幕和画面时间自动后移。
- **背景音乐**按成片时长自动在片尾淡出（`bgmFadeOut`，默认 5 秒），音乐文件比视频长就行。
- **竖屏版（小红书 / 视频号 / 公众号）**：`node engine/run.mjs 文案.md --竖屏`（先加 `--预览` 看版面），原生 1080×1920 排版，输出「文案名-竖屏.mp4」。
  - 版面：标题在上，内容依次往下，整块在 y 280~1320 的安全区里上下居中；字幕两行、底边距 380（避开平台底部界面）；页眉固定不随推镜跳动。
  - 素材：同名加 `-竖` 的图片优先（如 `东大-W01-…-竖.png`），没有才用原图；按图片真实比例排，不加说明条。
    截图卡用 `写稿/工具/vcard.py 配置.json` 从原始截图重新取景、配大字【译】条；数据图另画竖版（如 `图表/charts-竖.html`）。
  - 断行：`文案名.竖屏断行.json` 里写 `{"原句": "上半|下半"}`，字幕、标题（去掉 ==）、引用原文（可多个 |）都按它断。
  - 片头标题太长（冒号前超过 14 字，会被压成一行小字）时，在断行表里用 `#` 标题原文做键手动分行：`"主标题第一行|第二行||副标题"`（`||` 后是副标题，可省略；副标题字号不超过主标题的八成）。2026-10-05《被讨厌的勇气》竖屏首次使用。
  - 拆字幕时「」短引语和 “” 一样不从中间拆成两条（2026-10-05 起）。
  - 旧做法 `engine/vertical.py`（横屏画面放中间、上下加字）已不用。

## 六、常见问题

**Q：双击没反应／闪一下就没了**
用「终端」打开这个文件夹，跑一次看报错：
```bash
cd ~/Desktop/视频工厂 && node engine/run.mjs
```

**Q：报错「找不到可用的 Chrome」**
```bash
npx playwright install chromium
```

**Q：想只做某一个文案**
把文件拖到 `开始做视频.command` 图标上；或者终端里：
```bash
node engine/run.mjs "1-我的文案/你的文案.md"
```

**Q：想先看看效果，不想等渲染**
跑完一次后，双击 `engine/stage.html`，浏览器里会直接把动画播一遍（没声音）。

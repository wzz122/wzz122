样板：`~/Desktop/视频工厂/样片/2026-11-06-股神水谷v2/画面v6/`——`本期工具.py`、`工程/engine/stage.css` 末尾「v7b 新闻解说主题」、`质检/v7b检查.py`。新一期把 CSS 块、`本期工具.py` 里的 v7b 小工具、`素材/字体/` 拷进本期再改，不改样板原件。

## 1. 底

- 全片一个底色：极淡纸色纯色 `#ece5d8`（或别的单一纯色）。片头、序幕、结尾同一个底，**不换黑底**。
- 不画格线、纸纹、水渍、颗粒、暗角。
- 卡片（文字卡、引语卡、译文卡）：白底平卡，左侧 8px 色条（红 / 藏青 / 绿），一层很淡的投影，**不倾斜、不堆叠**。

## 2. 图片

- 一律原色，不加任何 filter（黑白、去饱和、调色、做旧、duotone 都不做）。
- 图是主角：满屏铺满（左侧渐变压暗，标题和字条用白字压在暗区），或宽 ≥ 画面 65% 居中、无白边相框。
- 截图（推文、持仓、券商弹窗、新闻网页）：放大到字看得清——高 ≥ 画面 60%；横条形截图铺满宽度。
- 停留：每张图 ≥2 秒；带字要读的 ≥3.5 秒或跟旁白念完。不用插镜、快切。
- 标签压在图上（下三分之一字条）或放在图旁，不要小卡配一堆小字。

## 3. 字

| 角色 | 字体 | 字号（1080p） |
|---|---|---|
| 标题 | 思源黑体 Heavy（或得意黑） | 64px 起 |
| 正文、说明 | 思源黑体 Regular / Medium / Bold | ≥40px |
| 标签、字条 | 思源黑体 Bold，方角色块白字 | ≥32px（字条常用 44px） |
| 大数字 | Oswald / Barlow Condensed SemiBold | 60px 起 |
| 日文原文 | Hiragino Sans 等黑体 | 可小（28px 左右），但旁边中文必须大 |
| 章卡章名 | 思源黑体 Heavy | ≥180px（样板 210px） |

- 字体均为 OFL，可免费商用；文件与授权放工程 `素材/字体/`，CSS 用 @font-face 引用。
- 不用宋体、楷体、行楷、手写体、圆体。
- 层级靠字号和粗细，不靠荧光笔和装饰。

## 4. 装饰与强调

- 荧光笔：全片 ≤3–5 处真正重点；标题里的 `==…==` 不画荧光（样板 CSS 已关掉）。
- 盖章：全片 ≤2–3 个，干净红框，不做残缺滤镜。
- 不用：胶带、回形针、折角、便签纸、手写旁注、圆角药丸标签、「—— 某某」落款、拟声大字、集中线、弹字、做旧暗角。
- 字条：下三分之一方角色块（中性墨色 / 正向绿 / 负向红），对应样板 `条()`。

## 5. 屏的结构

- 每屏 0.5 秒内主体上屏，不留空屏、半空屏。
- 章节：大字章卡（「第 N 章」红字 + 章名 ≥180px），不用几个小方框的关键词章卡。
- 结尾：干净大画面收住片名；不用 32 张缩略图回顾墙。
- 节拍「强」：数字砸停、推近、少量盖章；「松」：一张大图停 5–8 秒。

## 6. 数字

- 折线：线画到终点后终点数字再出现，或从起始值滚动；不从 0 滚。
- 负数、跌幅：滚动全程带「−」。
- 数字只来自证据卡。

## 7. 封面

- 同样换思源黑体 Heavy / 得意黑，去荧光笔；电影感封面工具 `写稿/工具/电影感封面.py` 目前写死兰亭黑（Lantinghei SC Heavy，系统附带字体，商用授权不明确），用前先换字体参数。

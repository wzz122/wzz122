## 2. 暗角

（2026-11-07 用户审片改）**v7b 不加暗角**，本节只作历史记录；满屏图要保标题可读时只在左侧加压暗渐变（见 v7b 规范）。

暗角就是画面四边压暗的一圈，像老放映机的片门，把视线收到中间。它是一层**固定在画面上、不跟镜头动**的遮罩（只有页眉、角标、字幕和底部导航画在它上面，不被压暗：右上章名、左下出处都落在暗角最深的那一圈里，参考片的角标也是压在暗角之上的），颜色 `#171516`（参考片四角实测 `#161415`–`#181715`）。左右重、上下轻。

| 离左右边 | 0px | 20px | 40px | 60px | 80px | 100px | 120px | 150px | 175px | 200px | 250px |
|---|---|---|---|---|---|---|---|---|---|---|---|
| 纸面亮度剩 | 9% | 16% | 25% | 35% | 46% | 56% | 67% | 81% | 90% | 96% | 99% |
| 遮罩不透明度 | 1.00 | 0.93 | 0.83 | 0.72 | 0.60 | 0.49 | 0.37 | 0.21 | 0.11 | 0.04 | 0 |

| 离上下边 | 0px | 10px | 20px | 40px | 60px | 80px |
|---|---|---|---|---|---|---|
| 纸面亮度剩 | 53% | 61% | 69% | 84% | 95% | 99% |
| 遮罩不透明度 | 0.51 | 0.43 | 0.34 | 0.17 | 0.05 | 0 |

四角取两张表里较大的那个不透明度。「纸面亮度剩」是该处亮度和画面中心之比，取 8 帧的中位数；帧与帧之间相差不到 1 个百分点，说明参考片的暗角是一层固定图层。

**内容安全区**：x 200–1720、y 80–900。视频工厂会把字幕烧进画面（`stage.css` 第 144 行）：字幕底边离画面底 86px，单行约 80px 高，占 y 914–994；两行时上到约 y 855。标题、图形、截图里的关键句都不放进字幕带，也不让暗角压住。有底部章节导航（72px）时，内容区高 1008，字幕带上移到约 y 842–922，安全区下沿改到 y 830。

**满屏素材上**：满屏实拍、新闻、生成片段出现时，暗角在 0.3 秒内降到上表数值的 30%，只留四角压暗；回到纸面再恢复。不能让新闻画面左右各黑掉 150px。

**第一次出样**：按上表的实测值出样（用户 2026-10-07 定），同一帧另出一张「不透明度 ×0.7」的对照。用户 2026-10-06 刚否掉过左右留白边，重暗角看起来可能像黑边，两张并排看过再定；定下的倍数写回本节。

## 4. 图版卡（每屏的主体）

一屏从上到下最多五层：

| 层 | 规格 | 出现时间 |
|---|---|---|
| 眉标 | 两种：①红色中文眉标，PingFang SC Semibold 24px，`#B03A33`，前缀「— 」，格式「— 话题 · 年份」；②灰色编号眉标，`#6B6760`，数字编号 + 中文，例「01 · 第一种解释」「CASE 02 · 第二个例子」 | 第 0 秒，逐字打出，约 10 字/秒 |
| 主标题 | ~~Songti SC Black~~ 思源黑体 Heavy / 得意黑（2026-11-07 用户审片改）；一行 96–120px，两行 80px，行距 1.15；墨黑 `#1E1C18`，1–3 个关键词换成红或藏青 | 眉标打完后 0.4 秒，墨晕显影 |
| 英文注 | 斜体衬线（Baskerville Italic 或 Georgia Italic）38px，`#6B6760`；只用来点题，不翻译整句 | 比主标题晚 0.5 秒，0.3 秒淡入 |
| 图形 | 见第 7 节节拍 | 跟着旁白 |
| 结论行 | ~~Songti SC Bold~~ 思源黑体 Bold（2026-11-07 用户审片改） 48px，放在图形下方；黑色，结论词用红 | 最后出现 |

间距：眉标离主标题 28px，英文注离主标题 24px。

**两种排法**：

1. **纸上直排**（默认）：图形和字直接放在格子纸上，常用「左图右字」（图占左 55%）或「上字下图居中」。
2. **居中竖卡**（用户参考图的样子）：一张卡片色的竖卡，约 960×1000，水平居中，上下几乎顶到暗角。卡里按上面五层排，但卡里的内容仍守安全区（下沿 y 900；有导航时 y 830）。适合「答案一 / 答案二」「两个例子对照」这类要和前后屏区分开的内容。

一张卡最多三种字体角色，例如：粗宋写说法，黑体写解释，等宽写年份和编号。

**规则**：

- 每期在稿子开头的「本期设定」里写明：红代表对立双方里的哪一方，藏青代表哪一方。整期不换，图表、标签、文字都按这个上色，观众不读字也知道这一块属于哪一方。
- 红一般给成本、问题、集中、机构一方；藏青给个人、分散、对照组一方。具体按本期内容定。
- 一屏最多两种强调色：红 + 藏青，或红 + 荧光黄。荧光黄只给「被点名的那一项」、结论数字和截图上的高亮。
- **荧光笔全片 ≤3–5 处真正重点，不给每个标题都划**（2026-11-07 用户审片改）；**荧光笔（黄色划线）一律正片叠底**：黄色压在字的下面，被划的字更醒目，不能变浅、变灰。USJ v6 第一版把叠底写在组件内层，外层元素自成一组，结果黄色盖在字上、被划的字对比度从约 7:1 掉到 2:1，2026-10-07 已在舞台样式里修（`.el.highlighter` 正片叠底）。每期静帧里看一眼：被划的字应该和没划的字一样黑。
- （2026-11-07 用户审片改）照片、截图、新闻画面、历史照片一律原色，**不做旧、不转棕褐、不去饱和**（旧引擎 `mediaGrade` 要设 0 或文件名带 `-原色`）。~~原：新闻截图、现场照片、实拍保留原色，只用工厂默认的轻度做旧；棕褐单色只给历史照片和人物剪贴。~~（依据：news-explainer `证据叙事与画面质感.md`「实拍保留自然色彩与肤色」；用户 2026-10-07「新闻截图要有图片」）

## 7. 节拍

| 项 | 规格 |
|---|---|
| 主效果和小变化 | 一屏一个**主效果**（版式自带的大动作，或一个 `[推近]` / `[盖章]` / `[印章]`，见 news-explainer `references/版式速查.md`「笔墨版式怎么用」最后一条）。「每句一个变化」指**小变化**：下一项出现、先灰后黑、标签亮起、数字落定。小变化不够就拆屏，不用 `[弹字]` 凑；`[弹字]` 一屏 ≤ 2 个 |
| 小变化的间隔 | 约 3 秒一个（一般 1.8–5.2 秒） |
| 一个画面节拍 | 平均 4–5 秒，范围 3–8 秒（只在校对页、分镜里计数，不上屏） |
| 一屏能停多久 | 20–60 秒都可以，前提是元素在一项项加；元素不加了就换屏 |
| 落定后静止 | 1.5–2.5 秒；大数字、问句 2–3 秒 |
| 对拍 | 动作落点卡在旁白念到那个词的时刻，±0.5 秒；数据点可以先摆好，标签等念到才出 |
| 先后 | 眉标、标题、图形外框比旁白早 0.5–1 秒；数据标签、数字落定卡在念到那个词的时刻（±0.5 秒）；原件和截图在旁白点名后约 1 秒出现（男女对立期「画面和旁白的先后」：参考片早 2–5 秒，我们先取保守值） |
| 先灰后黑 | 列表项、节点先用 `#9C978C` 出现，念到时 0.3 秒变成墨黑或主色 |
| 不清空 | 讲完一个模型，把它缩到 40% 退到左上角（0.5 秒），新内容在下面接着加 |
| 慢推 | 只在一屏停超过 15 秒时用一次，从 1.00 推到 1.03；不给每张图默认加，不循环（用户 2026-10-06 要求） |

**常用动作**：

| 动作 | 时长 |
|---|---|
| 描线生长（折线、圆环、箭头、红圈） | 折线约 1.5 秒；圆弧每段 0.75 秒 |
| 空心描边 → 实心砸入（公式、关键字） | 打字 1.25 秒，停 1.25 秒，砸入约 1 秒 |
| 柱子长高 + 数字滚动 | 1.25 秒，先快后慢 |
| 弹入回弹 | 0.25–0.5 秒 |
| 印章砸入 | 从 160% 大小、40% 不透明出现，0.15 秒缩到 100%；落定那一帧**只让印章和它压着的卡片**抖 3px，不抖整屏，0.1 秒回位；连盖时只第一枚抖 |
| 墨晕显影 | 约 0.5 秒 |
| 逐字打字（眉标、公式） | 约 10 字/秒 |
| 旧说法作废 | 变灰 + 红删除线，新说法下面刷一道藏青笔线 |

## 8. 换屏和转场

| 方式 | 规格 | 用在哪 |
|---|---|---|
| 纸上平移到下一站 | 0.25–0.5 秒，先快后慢，带轻微运动模糊 | 默认（工厂 `---` 已有） |
| 穿越推进 | 0.7 秒内推到 6–8 倍，冲进某个图形的开口，新屏从里面出来 | 从总图进入细节 |
| 旋转甩镜 | 1–1.25 秒，整张纸转约 30° 并平移约 1200px | 同一章内换角度 |
| 抽纸 | 0.75 秒，当前这张纸带透视滑出，露出下面那张 | 换语境；暗纸页和米色纸互换 |
| 墨迹擦屏 | 黑墨从左上泼过来盖满 0.5 秒，退去 0.5 秒露出新页 | 开章动作之一 |
| 老电视化 + 故障帧 | 纸面 0.1 秒变成圆角、重暗角、带划痕噪点的老电视画面 → 停 0.33 秒 → 1 帧横向撕裂、红蓝错位 → 硬切进实拍，同一刻配快门声 | 只用在纸面切进**满屏实拍**；截图和原件不走这个转场，它们留在纸面上推近 |
| 硬切 | — | 只用在实拍、截图、生成片段之间 |
| 接缝淡化（v6） | 上一镜头末帧冻结叠在下一镜头开头 0.25 秒退去，总时长不变 | 只用在章卡、结尾回顾墙前一刀（`项目.json`「接缝淡化」） |

除了平移，一期最多选 3 种换屏方式。各种方式的次数见第 14 节。

**不用**：闪白、翻页、每次转场配「嗖」。

## 9. 实拍和图片在纸面主题里怎么放

| 素材 | 做法 |
|---|---|
| 近年新闻、会议 | 满屏，角标隐藏，暗角降到 30%；叠横向扫描线（每 3px 一条，不透明度 6%）；每镜 2–3 秒，连用 3–4 镜就回纸面。原声每段 ≤ 10 秒，能用截图就用截图（用户 2026-10-06）。加「来源：频道｜日期」字条；开场「多台同播」10 秒以内不标来源（news-explainer 语言规范 12.3） |
| 档案老影像 | （2026-11-07 用户审片改）原样原色放大（满屏或宽 ≥65%），不加电视框、不放黑底小窗。~~原：老影像.py「电视框」缩成 75% 宽圆角小窗放黑底上~~ |
| 人物照片 | 公开、可用的人像才用。一律原色（2026-11-07 用户审片改），~~历史人物转棕褐单色加网点、撕纸毛边、投影~~ 停用。不配编造的对白气泡 |
| 网页、新闻截图 | **放大 + 高亮**（用户要求）：推近到关键句，让关键句的字和字幕差不多大；目标那一行加淡黄高亮或黄色扫光框，其余模糊 6px，四周压暗；~~可以旋转 8–12° 增加纸面感~~（2026-11-07 用户审片改：不倾斜，放大到高 ≥ 画面 60%）。外文截图旁边配中文译文。停到旁白把这句讲完 |
| 官方原件 | 证据三步（整页 → 推近关键句 → 中文译文）；关键句加高亮或黄色扫光框（用户要「重点放大、高亮」，不学参考片「原件上不加荧光笔」）；进场时四角出白色 L 形取景角（每角线长 40px、线宽 3px）；换下一份用 0.5 秒散焦切过去 |
| 论文 | （2026-11-07 用户审片改）~~同一张截图复制 3–4 份旋转堆叠飞入~~ 停用，一张正放大图；原：同一张截图复制 3–4 份，分别旋转 −8°、+5°、−3°，错开 30–60px，每 0.3 秒飞入一张；最后一张正放、推近到标题；作者、刊物、年份写进左下出处行 |
| 复刻件（重新排版的报告封面、表单） | 能用真截图就用真截图；用复刻件时出处行写「示意」，背景不放假字 |
| 实物照片 | 去背景，直接放在纸上，投影朝右下（第 13 节） |
| 地图 | 只用线稿轮廓或平涂剪影，不用卫星图；重点用「红点 + 细红引线 + 线描小图标」。**发中国平台的片子，画到中国国界的地图必须用带审图号的标准底图，否则不用地图**（不消费期拆解「不该学」第 2 条） |
| 隐私 | 评论、网页截图里的头像和昵称打码；未成年人和路人的脸局部打码，不整段模糊（男女对立期「图片处理」） |
| 生成片段 | 先裁掉四边黑边，再铺满；画风和规则见本目录《图像风格与复查规范》「生成镜头的两条规则」 |

## 10. 暗底变体（点缀，不做主模板）

（2026-11-07 用户审片改）**停用**：全片背景统一，序幕/片头不单独换黑底，不用暗纸页。

用户 2026-10-07 定：暗底页只作点缀。次数见第 14 节，每次不超过 20 秒，用「抽纸」进出。

- **暗纸页**：深炭灰纸 `#1F1E1C`，字用米白 `#E8E0D0`，强调用金 `#D8A830`；适合一节里最压抑的一小段。
- **金句卡**：米灰纸 `#D2CEC3`，中间一块黑矩形（x 210–1710、y 200–880），四边羽化 90px；白色 PingFang SC Heavy 约 120px，最多 2 行、每行不超过 10 字，居中。金句卡单独计数，不占暗纸页的次数；句子怎么写见 news-explainer `语言规范.md` 13.4。

暗纸页和金句卡都算档案纸这一套的变体。一期只用一套主模板，片尾预告也用这一套。

## 11. 成片里不能出现的

- 参考频道名、栏目名；参考片用过的代号、标签和标志性比方；参考片的固定角色和吉祥物（卡通长颈鹿、片尾 AI 吉祥物）、台标、片尾关注卡的样式；参考片那套四角角标的原样（见第 3 节）。
- 占位字样和空框：「B-ROLL」「TODO」「插入」「占位」「lorem ipsum」、空的取景角框、空素材框。
- AI 生成的写实真人；真人照片配编造的对白。
- 制作指令、审稿备注。

## 12. 检查

1. **第一次落地**：样图和参考图并排，再和一张带硬字幕、带底部导航的工厂帧并排，比纸色、格线深浅、暗角宽度（实测值和 ×0.7 两张）。用户点头再推广。
2. **每期校对页**：拼图看右上章号、章名和 `##` 是否一致；红、藏青有没有中途对调；一屏有没有超过两种强调色。
3. **每期导出**：抽帧看暗角有没有压到标题、截图关键句和字幕；按第 1 节量一次格线深浅。

## 13. 立体感（不用真 3D，也不花钱）

（2026-11-07 用户审片改）**停用**：不要倾斜卡片、堆叠投影、纸面透视；层级靠字号、粗细和图的大小。

用户 2026-10-07 要求「特效更立体」。下面这些做法都是平面效果叠出来的纵深。

| 做法 | 规格 |
|---|---|
| 统一光源 | 所有投影朝右下，像左上方有一盏台灯；卡片投影 `0 6px 18px rgba(40,30,20,.12)`，实物 `12px 18px 28px rgba(40,30,20,.30)` |
| 卡片悬浮 | 纸上的卡片倾斜 1–5°，左边可加 10px 藏青粗边，像档案卡 |
| 纸面当地面 | 需要「场景感」时，整张纸做透视倾斜（`perspective:1600px; rotateX(30°–40°)`），格子跟着透视，柱子、卡片在上面投影；次数见第 14 节 |
| 前后层视差 | 一屏分 2–3 层（底纸 / 卡片 / 前景标注），镜头平移时各层速度不同：前景快、底纸慢。视差就是近的东西动得快、远的动得慢，看起来就有前后 |
| 景深 | 截图只留目标那一行清楚，其余模糊 6px；点阵推进时前面的点虚焦变大。景深就是「一处清楚、前后模糊」，像相机对焦 |
| 暗角当灯光 | 中心像被台灯照亮，视线集中（第 2 节） |
| 纸模型道具 | 贯穿道具和重点章的道具用 `[线描]` SVG 加投影，做成平面纸模型的样子；真 3D 道具（蛋糕、多米诺、舞台）暂不做，要做先报价 |

这些效果大多要引擎配合，上线前不硬凑；出样时逐条看哪条已经能做。

依据：不消费期拆解「立体感」7 条、「可直接搬进」第 13 条（卡片投影 1–5°、纸面透视、多层纸雕视差）；男女对立期「立体感」第 2、4 条（透视面板、叠纸投影）。

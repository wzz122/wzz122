# 拍摄清单模板（每家店现场照着拍）

## 拍前设置（一次就好）
- 竖屏 9:16，**4K 30fps**；动作镜头另拍 **1080p 120fps**（慢动作）
- iPhone：设置 → 相机 → 关闭「HDR 视频」（避免剪出来发灰；脚本能处理但关掉更稳）
- 用 1x 或 2x 镜头，**不要用 0.5x 广角**拍食物（会变形）
- 长按屏幕锁定对焦/曝光（AE/AF 锁定），曝光往下拉一点，保住油光高光
- 擦镜头！靠窗坐，避开头顶直射灯
- 每个镜头**开拍后静止 1 秒再动，动完再停 1 秒**（给剪辑留余量），每条 3–6 秒
- 每个镜头拍 2 条

## 必拍镜头（每家店）

| # | 镜头 | 时长 | 要点 | 用途 |
|---|---|---|---|---|
| A1 | 店门口/招牌 | 3s | 慢慢推进，或 POV 推开门走进去 | 可信度 |
| A2 | 菜单/价签 | 3s | 价格清楚可读，慢推 | 价格冲击 |
| A3 | 店内氛围/厨房 | 3–5s | 煎烤、出餐、倒酒，**收原声** | ASMR、过渡 |

## 每道菜 5 连拍（主菜必须全拍，配菜拍 1–3）

| # | 镜头 | 时长 | 要点 |
|---|---|---|---|
| B1 | 俯拍全景 | 3s | 手机平举在正上方，慢慢平移或旋转 |
| B2 | 45° 慢推 | 4s | 从中景推到最有质感的地方（断面/油光/焦边） |
| B3 | **动作镜头** | 4s ×2 | 夹起/切开/拉丝/浇汁/蘸酱 —— 120fps，**收原声** |
| B4 | **举到镜头前** | 3s | 手拿/筷子夹起，送到镜头前 20cm，背景虚化 → **封面候选** |
| B5 | 吃一口 | 3s | 只拍嘴或侧脸，咬下去的瞬间 |

## 现场要记下来（发给 Claude 写文案用）
- 店名、最近车站 + 步行几分钟、营业时间、定休日
- 每道菜名 + 价格
- 你自己最真实的一句感受（越具体越好：「皮像饼干一样咔嚓响」）
- 这家店的**反差点**是什么？（便宜得离谱 / 量大 / 没见过的吃法 / 比某名店还好吃）

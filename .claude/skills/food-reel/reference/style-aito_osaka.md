## 2. 封面公式（每条都一样，强品牌识别）

```
┌──────────────┐
│(谷町) ← 白色圆形地名徽章，黑字
│ ク
│ ッ   ← 竖排钩子：感官比喻 / 情绪词 / 对标
│ キ      白字 + 黑色描边/阴影，粗黑体
│ ー
│ の
│ な 幻のクレープ ← 横排主标题＝菜名（加修饰），最大字号
│ 👁 226万
└──────────────┘
```
- 画面：**手举/筷子夹起的食物怼近镜头**，占画面 60–80%，背景虚化，暖光。
- 竖排最后一个字和横排标题在同一行 → 读起来是一句话。
- 文字都在 3:4 安全区内（主页网格会裁掉 9:16 的上下）。

**钩子词库**（日→中可用的对应）
- 情绪：背徳の / 背徳すぎる（罪恶感满满的）、絶対に沼る（绝对会上瘾）、酸欠になる（好吃到窒息）
- 稀缺：幻の（梦幻的/传说中的）、噂の（传说中的）、究極の（终极）
- 口感比喻：トロトロの（软糯到化开）、クッキーのような（像饼干一样的）、飲める〇〇（能喝的〇〇）
- 数量/价格：無限（无限）、極厚（超厚）、コスパ最強（性价比天花板）
- 对标：〇〇越えの（吊打〇〇的，〇〇＝人人都知道的连锁）

## 3. 视频结构（15–25 秒）

| 时间 | 内容 | 画面 | 旁白 |
|---|---|---|---|
| 0–2s | **钩子** | 最强的动作镜头（夹起/拉丝/浇汁/切开），封面字叠加 | 地名 + 钩子 + 菜名，一口气说完 |
| 2–4s | 可信度 | 店门口/招牌/暖帘 POV 走进去 | 店的一句话定位 |
| 4–15s | 主菜 1–3 道 | 每道：俯拍→推近→动作→举到镜头→吃一口 | 每镜一句感官描写 |
| 15–18s | 价格冲击 | 菜单/价签特写 or 菜+价格大字 | 「这个居然只要〇〇元」 |
| 18–20s | 信息 + CTA | 店信息卡 | 「先收藏」「下次一定去」 |

## 4. 运镜（推断，按这种类型通行做法）

1. **夹起慢升（Chopstick lift）**：筷子夹起食物缓慢上抬，镜头固定或微跟 → 最常用的封面镜头
2. **举到镜头（Hold-up）**：手拿食物从下往上送到镜头前 20–30cm，背景虚化
3. **慢推（Push-in）**：45° 角从中景缓慢推到质感最强的部位（油光、断面、焦边）
4. **俯拍全景（Top-down）**：手机平放在桌子正上方，可轻微旋转/平移
5. **动作 ASMR**：浇汁、切开、拉丝、蘸酱、煎烤滋滋声 —— 可用 60/120fps 慢动作，**保留原声**
6. **POV 进店**：从门外推开暖帘走进去，1–2 秒
7. **吃一口**：只拍嘴/侧脸，咬下去的瞬间切

剪辑节奏：平均每镜 0.7–1.5 秒；**切点卡在旁白的句读上**；前 3 秒不放任何静态/慢的镜头。

## 5. 文案/配音

- 语速快（日语约 7–8 拍/秒，中文约 5–6 字/秒），口语、第一人称、像跟朋友安利。
- 每句话 ≤ 15 字，一句话配 1–2 个镜头。
- 大量**拟声/口感词**：日 サクサク・トロトロ・ジュワッ・カリッ；中 外酥里嫩、爆汁、拉丝、入口即化、咔嚓。
- 字幕 = 旁白原文（或精简版），关键词（价格、口感词）**黄色高亮**。
- 结尾固定 CTA，形成系列感。
- 音乐：轻快的 lo-fi / city pop，音量压低在人声下面 —— **建议在 Instagram 发布时用 App 内热门音乐**（有版权 + 推流加成）。

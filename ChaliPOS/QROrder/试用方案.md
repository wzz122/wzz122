# 茶里茶里 扫码点单 · 最小试用方案

## 一句话

顾客排队或坐下时扫码，用手机点单 → 柜台平板「叮咚」一声，订单出现 → 店员照着把单录进店里原来的 スマレジ・ウェイター（橙色那个），再用 Smaregi 结账 → 在平板上点「已录入」「做好了」，顾客手机上的状态会跟着变。

以后怎么升级（去掉手动录入、手机付款、一整套）见 [路线图.md](路线图.md)。

**老板的收银系统一点不动，费用 0 元，不想用了撕掉二维码就行。**

演示视频：`茶里茶里_扫码点单_试用演示_v2.mp4`（云盘 `06_应用自动生成/项目文档/茶里茶里扫码点单/`）

## 柜台平板怎么用（店员看这里）

1. 开店：打开接单屏（会直接显示订单）→ 点一下屏幕，打开提示音 → 点左上角「已暂停 · 点这里开始接单」，变成绿色「● 接单中」。
2. 来新单：平板「叮咚」响，第①列出现带橙色边框的卡片，比如「Q1」。顾客改过的选项（少冰、甜度 70% 等）标黄。
3. 顾客到柜台报「Q1」→ 店员照着卡片在 スマレジ・ウェイター 里录入（卡片上标了分类，比如「鲜果时光」，按分类找就行；Q 号可以写进桌号或备注）→ 用 Smaregi 收款 → 在平板上点「已录入收银 · 已收款」。顾客手机显示「制作中」。
4. 做好了 → 点「做好了（通知顾客）」。顾客手机显示「可取餐」并震动。
5. 顾客取走 → 点「顾客已取走」，卡片消失。
6. 其他：
   - 卖完的饮品：点右上「售罄」，再点那款饮品，然后保存。第二天会自动恢复。
   - 要暂停：点「● 接单中」。
   - 今天的单数和金额：点「今日记录」。
   - 客人当面用外语说名字、你一下找不到：点「🔍 查饮品」，打几个字（平假名、片假名、英文、中文都行）。
   - 点错了：卡片上有「↩ 退回」。顾客不要了：点「取消」，可以写原因。

## 你先自己测一遍（上线后）

不用去店里，自己一台手机加一台电脑（或平板）就能测：

- [ ] 电脑或平板打开**接单屏链接**（第一次用带密钥的那个链接），点一下屏幕，再点「开始接单」
- [ ] 手机扫二维码（或直接打开**顾客页面链接**），点一杯，备注写点什么，下单，记住单号
- [ ] 3 秒内平板响「叮咚」，出现这张单，内容和手机上一样
- [ ] 点「已录入收银」→ 手机变「制作中」；点「做好了」→ 手机变「可取餐」
- [ ] 手机切到 English 再点一单，看平板上是不是中日文
- [ ] 标一款售罄 → 手机刷新后那款显示「售罄」，点不了
- [ ] 点「接单中」暂停 → 手机刷新后提示「请到柜台点单」
- [ ] 「今日记录」里有刚才的单
- [ ] 「查饮品」里打「まんご」「mango」「芒」都能找到芒果类

## 一台 iPad 能不能搞定？

店里那台 iPad 已经装着 スマレジ・ウェイター、Smaregi、楽天ペイ。接单屏是网页，可以试试和 Waiter 分屏：

1. 打开 スマレジ・ウェイター
2. 从屏幕底部往上轻轻滑，调出底部的程序栏（Dock）
3. 把 Safari 图标拖到屏幕右边 → 如果出现左右两半，就成功了（接单屏在窄窗口里也能正常看，我测过）
4. 拖不进去，说明 Waiter 不支持分屏。那就在旁边放一台旧手机或旧平板专门开接单屏，或者在两个软件之间来回切

模拟器里装不了 App Store 的软件（Waiter、Smaregi、楽天ペイ 都装不了，而且要店里的账号才能登录），所以分屏只能在店里那台 iPad 上试。接单屏本身我已经在 iPad 模拟器的 Safari 里测过，显示和接单都正常。

哪里不对、哪里不顺手，直接告诉我就行。

## 还没在店里确认、我先按常见做法设的

在店里对一下，有不一样的告诉我：

- 只有珍珠奶茶能做热的（菜单屏上写的），其他只能冷饮
- 冰沙（4 款「〜スムージー」）不能调冰量
- 所有饮品都能调甜度，都能加任何小料
- 珍珠奶茶标明「含珍珠」
- 榴莲那款的中文名暂时写「榴莲芒芒」
- 店内和外带同一个价格（含税价不变）

## 现在这个版本的限制

- 顾客还是要到柜台付款。以后可以再加在线付款
- 店员要把单子再录一次收银软件
- 顾客手机要能上网
- 平板要一直开着接单屏，不要锁屏。iPad 可以在「设置 → 显示与亮度 → 自动锁定」里选「永不」
- Supabase 免费项目连续 7 天没人用会自动暂停（比如店休超过一周）。到时在 Supabase 后台点一下就能恢复

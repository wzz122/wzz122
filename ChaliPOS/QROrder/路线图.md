# 茶里茶里 点单系统路线图

## 总原则

- **每一步都可以单独停下来**，不影响店里正常营业。
- **先用数据说话，再决定花不花钱**：接单屏的「今日记录」会记下每天有多少扫码单。
- **老板的 Smaregi 一直是记账的正本**：建议「接上 Smaregi」，而不是「换掉 Smaregi」。

## 第 1 步：过渡版（现在做，0 元）

**流程**：客人排队或坐下时扫码点单 → 柜台平板（或同一台 iPad 分屏）显示订单 → 店员照着录进 スマレジ・ウェイター → 用 Smaregi 结账（现金、楽天ペイ、PayPay 都照旧）→ 在平板上点「已录入」「做好了」，客人手机提醒取餐。

**解决的问题**

- 少解释：页面上有「第一次来？」说明（含不含珍珠、能不能做热、甜度怎么选），还有日文 / 中文 / 英文三种语言。
- 少听错：订单写得清清楚楚，改过的选项标黄；客人当面用外语说名字时，用「查饮品」打几个字就能找到。
- 排队时间不浪费：排队的地方贴二维码，轮到时客人已经点好了。

**还没解决的**：要手动录一次 Waiter；还是到柜台付款。

**试用 1～2 周，看这几件事**

| 看什么 | 去哪看 |
|---|---|
| 每天有多少扫码单 | 接单屏「今日记录」 |
| 扫码单占全部单的几成 | 今日记录 ÷ Smaregi 当天单数 |
| 高峰时排队有没有变短、店员有没有更轻松 | 店员的感觉、老板的观察 |
| 有没有录错、听错 | 店员记一下 |

**需要老板同意**：贴二维码；柜台多放一台平板或旧手机（也可以试试在同一台 iPad 上分屏）。

**上线**：Supabase 免费版 + GitHub Pages，约 20 分钟（等你同意）。

## 第 2 步：去掉手动录入（老板觉得有用以后）

两条路，二选一：

| | A：Smaregi 官方モバイルオーダー | B：我们的系统 + Smaregi 接口自动录入 |
|---|---|---|
| 做法 | 在 Smaregi 后台开通，菜单在 Smaregi 里设置 | 扫码订单通过 Smaregi 的接口自动写进 Waiter |
| 月费 | フードビジネス新套餐每月 15,400 日元（含税，含扫码点单）。在用旧套餐的店要加扫码点单，也必须换成新套餐 | 如果现在的套餐已经能用接口，就没有额外月费（接口一般要「プレミアム」以上，需要确认） |
| 优点 | 官方产品，有客服；订单直接进收银；可以手机付款 | 保留我们的多语言说明、查饮品、「第一次来？」；省月费 |
| 缺点 | 有月费；菜单要在 Smaregi 里重新设置；多语言做到什么程度要看官方 | 要开发和测试（估计 2～4 周）；坏了要自己修；要老板在 Smaregi 后台开开发者权限 |

**先要弄清楚的一件事**：老板现在用的是 Smaregi 哪个套餐（Smaregi 管理画面 → 契約情報）。这决定了 A 要多花多少钱、B 能不能做。

## 第 3 步：手机上直接付款（可选）

- 走 A：官方自带。
- 走 B：接 PayPay、Stripe 等，手续费大约 3%，需要老板的商户账号。
- 好处：付完款直接开始做，客人不用再排队付款。

## 第 4 步：一整套（以后再说）

| 内容 | 难度 | 说明 |
|---|---|---|
| 叫号屏（店里的电视显示「可取餐」号码） | 低 | 很便宜，可以早做 |
| 会员积分、优惠券 | 中 | Smaregi 也有类似功能，先看官方 |
| 完整的收银系统（仓库里已经有 ChaliPOS iPad App 原型） | 高 | 换掉 Smaregi 风险大：报税和发票（インボイス）、楽天ペイ刷卡机联动、员工重新培训。除非 Smaregi 明显不够用，否则不建议换 |

## 每一步给老板看什么

| 步骤 | 花费 | 老板要做的 | 判断标准 |
|---|---|---|---|
| 1 过渡版 | 0 元 | 同意贴二维码，柜台放一台平板 | 两周后扫码单够多、店员觉得轻松 |
| 2A 官方 | 每月 15,400 日元 | 在 Smaregi 开通，设置菜单 | 扫码单多到手动录入成了负担 |
| 2B 自动录入 | 开发时间（几乎不花钱） | 确认套餐，开接口权限 | 同上，而且老板不想加月费 |
| 3 手机付款 | 手续费约 3% | 开商户账号 | 柜台付款还是排长队 |
| 4 一整套 | 看功能 | 看功能 | 前面几步都稳定以后再说 |

# T6 Lightroom 人工验收操作说明

这一步只能人工做（Lightroom 没有可自动化的导入接口）。全程约 15–20 分钟。

## 目录里有什么

每组 3 个文件（共 8 组）：

| 文件 | 用途 |
| --- | --- |
| `T6_XX_..._source.png` | 原图，导入 Lightroom 用 |
| `T6-XX_....xmp` | ColorMatch 导出的预设，应用到上面的原图 |
| `T6_XX_..._local_render.png` | App 同参数的本地渲染，是比对基准 |

## 操作步骤（Lightroom Classic）

1. 把 8 张 `_source.png` 全部导入 Lightroom。
2. 左侧「预设」面板 → 右上角 `+` → **导入预设**，把 8 个 `.xmp` 全选导入
   （它们会出现在 ColorMatch 组下）。
3. 逐张选中原图，点对应编号的预设（T6-01 配 T6_01，以此类推）。
4. 每张应用后截一张屏（`Cmd+Shift+4` 框选照片区域即可），
   截图存回本目录，命名 `T6_XX_lightroom.png`。

Lightroom（云版）同理：编辑面板 → 预设 → 三个点 → 导入预设。

## 看什么（每组 10 秒）

把 Lightroom 效果和同编号的 `_local_render.png` 摆在一起，看三处：

- **肤色**（01 人像、07 猫）：是否同样的暖度，不发橙、不发灰。
- **天空/水面**（05 逆光、06 海景）：蓝青色方向是否一致。
- **中性灰/白墙**（04 站台、08 室内）:是否同样偏色，不额外染色。

方向一致、程度接近 = 通过；肉眼明显不同方向（一个偏暖一个偏冷）= 不通过，
记下编号。

## 完成后

把 8 张 `T6_XX_lightroom.png` 存回本目录后，在 Claude Code 里说一声
「Lightroom 截图回传了」，我会做逐组比对并把结论写进
`T6_RESULTS.md`，完成 M1 最终验收。

---

技术备注：这批 XMP 由 ColorMatchCore 的 `XMPWriter` 真实生成（与 App 内
导出同一条代码路径）；`_local_render.png` 由同一份参数经 `LUT` +
`PreviewRenderer` 渲染——所以这次比对验证的正是「预览 = 导出」这条产品红线。
参数从验收三联图切片重新计算，与 `T6_RESULTS.md` 表中数值略有出入属预期
（原始图对未随仓库交付），不影响红线验收的有效性。

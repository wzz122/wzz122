# go_soso / wzz122

我在做一些小而实用的 Apple 平台工具、中文用户在日本生活/学习会用到的 App，以及能减少重复工作的自动化流程。

I build practical macOS utilities, iOS learning apps for Chinese-speaking users in Japan, and small automation workflows that make daily work lighter.

## Works for People

| Project | What it does | Stack |
|---|---|---|
| [PreciseSearch](https://github.com/wzz122/PreciseSearch) | macOS 本地文件名精准搜索工具，用来补足 Finder / 文件打开面板里偏模糊的搜索体验。 | Swift, SwiftUI, Spotlight |
| [WinScrollMac](https://github.com/wzz122/WinScrollMac) | macOS 菜单栏工具，让外接鼠标像 Windows 一样滚动，同时保留触控板自然滚动。 | Swift, Event Tap, Menu Bar |

## English

I am focused on compact, useful software:

- macOS utilities that fix small daily workflow problems.
- iOS learning apps for Japanese exams, local life, and practical study.
- App release support: privacy pages, support pages, TestFlight prep, and store-readiness checks.
- AI-assisted development workflows with Codex, Claude, and Gemini.
